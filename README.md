# 🎵 Music Streaming Analysis: Springfield vs. Shelbyville

## 📌 Project Description
Analysis of music streaming data comparing user behavior between the cities of 
Springfield and Shelbyville. The project tests data-driven hypotheses about 
listening preferences and activity patterns using real-world datasets.

## 🎯 Objectives
- Compare music listening habits between Springfield and Shelbyville users
- Identify trends in streaming activity by day of the week
- Test and validate hypotheses using data analysis techniques
- Clean and prepare datasets for analysis

## 🔍 Key Finding
> Springfield shows a considerably higher volume of user activity compared to 
> Shelbyville across all days analyzed. The hypothesis was **confirmed**: user 
> activity differs depending on both the day of the week and the city.

## 🛠️ Technologies Used
- Python
- Pandas
- Jupyter Notebook
