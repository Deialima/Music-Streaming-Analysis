# Music Streaming Analysis: Springfield vs. Shelbyville
## Project Description

This project analyzes music streaming data to compare user listening behavior in the cities of Springfield and Shelbyville. Using real-world datasets, the analysis focuses on testing hypotheses and identifying patterns in music preferences and user activity.

The project includes data preprocessing, exploratory data analysis (EDA), and hypothesis testing to better understand differences between the two populations.

## Objectives 

Compare music listening habits between Springfield and Shelbyville users
Identify trends in music preferences and streaming activity
Test hypotheses using data analysis techniques
Clean and prepare datasets for analysis
